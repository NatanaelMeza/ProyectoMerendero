Puente de Sonrisas

Esta página web, creada con HTML y CSS, tiene como objetivo ayudar a niños, adolescentes, adultos y adultos mayores a recibir un plato de comida en sus hogares, 
juguetes para los más pequeños y ropa para todas esas personas. La web muestra la ubicación, horarios y necesidades de cada merendero, además de facilitar 
el contacto con los encargados, creando así un puente solidario entre quienes necesitan y quienes desean ayudar.
